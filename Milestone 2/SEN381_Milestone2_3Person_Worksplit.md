Milestone 2 — 3 Person Work Split

Based on the official Milestone 2 brief. This document allocates primary ownership
while maintaining shared engineering accountability.

Person 1 — Architecture & Quality Drivers

Owns system architecture and PED evolution.

• Review and update PED v2.0 from M1

• Architecture Significant Requirements (ASRs) & quality drivers

• Architecture alternatives and justification

• Logical architecture diagrams

• Architecture ADRs

• M2 baseline sign-off

• Update RTM architecture columns

Person 2 — Data, Persistence & Technology

Owns database and technology decisions.

• Initial ERD / data model

• Entity relationships & ownership

• Persistence decisions and database justification

• Technology stack comparison & selection

• Deployment compatibility assumptions

• Technology ADRs

• Update RTM data & technology columns

Person 3 — Design, Development & Governance

Owns implementation evidence and repository governance.

• Two genuine design problems

• Final design-pattern decisions (A2 informed)

• Interface / API decisions

• README & application documentation

• GitHub governance & repository evidence

• RTM implementation & verification columns

• Risk Register and AI Register updates

Shared Responsibilities (All Members)

• Review PED v2.0 for consistency

• Proofread formatting and grammar

• Maintain Harvard references and citations

• Update RTM for individual sections

• Use feature branches and meaningful commits

• Review teammates' Pull Requests

• Participate in ADR discussions

• Verify AI-assisted work

• Prepare the presentation

• Be able to defend every artefact
